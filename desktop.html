Windows Installation & Setup

Beside for Windows is available in two official 64-bit distributions:

Setup Installer (Recommended)

Beside-Setup-v0.1.1-x64.exe (11.98 MB)
Official Inno Setup installer. Creates Start Menu and Desktop shortcuts, registers clean uninstallation, and configures Windows Explorer context menu integration.

Download Installer (.exe)

Portable ZIP Archive

Beside-v0.1.1-Windows-x64.zip (14.25 MB)
Zero-install archive. Extract to any folder and launch Beside.exe directly without administrator rights.

Verifying SHA-256 Checksums (PowerShell)

Always verify the integrity of downloaded binaries in Windows PowerShell before running:

Get-FileHash -Algorithm SHA256 Beside-Setup-v0.1.1-x64.exe
# Expected: 998342efed9e95a1707cc82a337c0c95b45695269c66dc375ecbcf6126546e6a

Get-FileHash -Algorithm SHA256 Beside-v0.1.1-Windows-x64.zip
# Expected: c63d7859d20efb4917141a8ec0568de71bb55f6273b097430ba2342cb2ee0f0b

Upgrading & Uninstalling

  • Upgrading: Running a newer Setup Installer automatically closes any active Beside.exe process and upgrades in place while preserving your paired peers and Beside Pro license.
  • Uninstalling: Uninstall via Windows Settings → Apps → Installed apps → Beside. When online, the uninstaller automatically releases your Beside Pro device activation slot.

System Requirements (Windows 10 / 11)

  • Operating System: Windows 10 (version 1809 / build 17763 or later) or Windows 11.
  • Architecture: 64-bit (x64 / AMD64).
  • Memory (RAM): Minimum 100 MB available RAM. File streaming uses a bounded 64 KB memory buffer regardless of file size.
  • Network: Wi-Fi or Ethernet connection on the same local router subnet as your peer device, or direct connection to an Android Mobile Hotspot.
  • Display & Paths: Per-Monitor v2 High-DPI awareness and Win32 long path support (<longPathAware>) for deep folder hierarchies.

Device Discovery & Connection Troubleshooting

Beside discovers nearby devices automatically using mDNS/DNS-SD (_beside._tcp.local.) over UDP multicast (224.0.0.251:5353). If your peer device does not appear on the Windows radar:

1. Confirm Both Devices Are on the Same Subnet

Ensure your Windows PC and Android device are connected to the same Wi-Fi router (e.g., both assigned 192.168.1.x). Avoid connecting one device to an isolated guest SSID or a double-NAT repeater.

2. Bypass Wi-Fi Client / AP Isolation

Public, hotel, university, and guest Wi-Fi networks often enable Client Isolation, which prevents devices on the same Wi-Fi from seeing each other.

Mobile Hotspot Workaround: Turn on the Wi-Fi Hotspot on your Android phone and connect your Windows PC directly to it. Beside transfers directly over the local hotspot at full Wi-Fi speed without using mobile data.

3. VPNs & Virtual Switches (WSL2, Hyper-V, Docker)

If you run a VPN on Windows, enable Allow LAN Traffic or Split Tunneling in your VPN client. Beside automatically ignores virtual switches (WSL, Hyper-V, Docker, VMware) so mDNS binds to your physical LAN interface.

4. Connect by IP:Port or QR Code

If your router drops UDP multicast packets, click Connect by IP / QR in Beside to enter the peer's local IP and port directly or display a QR code for your phone to scan.

Sending & Receiving Files on Windows

Sending Files, Folders & Text

  • Drag-and-Drop Radar: Drag files or folders from Windows Explorer onto the Beside window or directly onto a discovered peer card.
  • Windows Explorer Context Menu ("Send with Beside"): Right-click any file or folder in Windows Explorer and select Send with Beside.
  • Windows SendTo Shortcut: Right-click any selection in Explorer → Send to → Beside.
  • Direct Text Messaging: Send clipboard snippets, terminal commands, or URLs directly to your peer without creating temporary files on disk.

Receiving Files, Native Toasts & System Tray Mode

  • Default Save Folder: Received files are saved to Downloads\Beside (or any custom folder configured in Beside Pro).
  • Auto-Rename Collision Protection: Existing files are never overwritten; duplicate names automatically receive a numeric suffix such as document (1).pdf.
  • Interactive WinRT Toast Notifications: Incoming transfers show native Windows notifications with Accept and Decline buttons, plus Copy for text snippets and Open folder upon completion.
  • System Tray & Start with Windows: Closing the window keeps Beside running quietly in the Windows System Tray. Right-click the tray icon to pause receiving, toggle Auto-Accept, or quit.

Device Pairing & Security

  • Mutual TLS 1.3 Only: Every transfer is encrypted end-to-end with TLS 1.3 (rustls + ring) and verified against pinned X.509 SPKI SHA-256 certificate fingerprints.
  • 8-Digit SAS Verification: During first-time pairing, compare the 8-digit Short Authentication String on your Windows PC and Android device to prevent Man-in-the-Middle (MITM) interception.
  • Windows DPAPI Key Storage: Your PC's private identity key is encrypted at rest using the Windows Data Protection API (DPAPI).
  • Auto-Accept (Beside Pro): Pro users can enable Auto-Accept for trusted paired devices. Unpaired devices always require manual approval.

Firewall & Network-Related Issues

1. Switch Windows Network Profile to "Private"

  1. Open Windows Settings → Network & internet → Wi-Fi (or Ethernet).
  2. Click your active network connection.
  3. Set Network profile type to Private network so Windows allows local peer discovery.

2. Allow Beside.exe in Windows Defender Firewall

  1. Open Start, search for Allow an app through Windows Firewall, and press Enter.
  2. Click Change settings, find Beside (Beside.exe), and ensure Private (and Public if using hotspots) is checked.

3. Local Ports Used by Beside

  • UDP Port 5353 (Multicast 224.0.0.251): mDNS peer discovery (_beside._tcp.local.).
  • TCP Port 61734 (or advertised ephemeral port): Direct Mutual TLS 1.3 peer-to-peer data transfer.

Frequently Asked Questions (Desktop)

Should I install the .exe Setup Installer or use the Portable .zip?

Use the Setup Installer (.exe) for automatic Start Menu shortcuts, Explorer context menus, and easy upgrades. Use the Portable Archive (.zip) if you do not have administrator permissions.

How do I access "Send with Beside" on Windows 11?

In Windows 11 Explorer, press Shift + Right-Click (or click Show more options) to select Send with Beside, or use Send to → Beside.

Can a Free Windows PC receive unlimited files from a Beside Pro phone?

Yes. Receiving from a Beside Pro sender is always unlimited and free. Free tier limits apply only to outgoing transfers initiated from a Free device.

How do I hide message previews in Windows desktop notifications?

Go to Settings → Notifications in Beside and turn on Hide message previews.

Known Issues & Solutions (Desktop)

Issue: Windows SmartScreen displays "Windows protected your PC" (Unrecognized App)

Why this happens: Windows Defender SmartScreen utilizes a cloud reputation database. Because Beside is an independent release distributed outside the Microsoft Store, each new version starts with zero cloud reputation until thousands of downloads have accumulated across Windows devices worldwide.

How to Safely Verify and Run

  1. Verify the SHA-256 hash in PowerShell: Get-FileHash -Algorithm SHA256 Beside-Setup-v*.exe and check against our official SHA256SUMS.txt.
  2. In the SmartScreen dialog, click the blue More info link.
  3. Confirm the publisher and file name, then click the Run anyway button.

Issue: WinRT toast notifications do not pop up during full-screen apps

Solution: Windows Focus Assist / Do Not Disturb suppresses toasts during full-screen apps. You can still approve incoming transfers directly inside the Pending Requests queue on the Beside home screen (valid for 60 seconds).

Issue: Reinstalling Windows left an old PC activation slot occupied

Solution: Visit the Beside Pro Device Manager, log in with your license key, and revoke the old PC slot.
